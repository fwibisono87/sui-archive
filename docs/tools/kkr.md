# kkr (retired)

Earlier versions of this guide recommended `kkr` for recording YouTube live streams because `yt-dlp`'s live support was then immature. The project no longer appears to be actively maintained, and this guide no longer recommends installing it.

Use the maintained [`yt-dlp` guide](./yt-dlp.md) and the dedicated [Live streams](../live-streams.md) workflow instead. They cover scheduled starts, live-from-start behavior, DVR limitations, sidecars, and post-stream recovery.

This page remains at its old URL so bookmarks lead to an explanation instead of a broken page. It is not an installation guide.
